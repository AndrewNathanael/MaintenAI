# ⚙️ Predictive Maintenance Sensor Analytics & Risk Prediction Dashboard

Aplikasi end-to-end Machine Learning & Dashboard Analytics untuk memprediksi potensi kegagalan mesin (*Machine Failure*) berbasis data sensor IoT secara real-time.

## 📌 Fitur Utama
1. **Interactive EDA Dashboard**: Visualisasi distribusi status mesin, heatmap korelasi sensor, dan scatter plot interaktif dengan Plotly.
2. **Real-time Failure Risk Simulator**: Input parameter sensor via slider untuk mendapatkan estimasi probabilitas risiko kerusakan mesin secara instan.
3. **Batch CSV Prediction**: Memungkinkan pengguna mengunggah file CSV berukuran besar dan mengunduh hasil analisis risiko secara langsung.

## 🛠️ Tech Stack
- **Bahasa**: Python 3.10+
- **Machine Learning**: Scikit-Learn (Random Forest), Joblib
- **Data Processing**: Pandas, NumPy
- **Visualisasi**: Plotly Express, Plotly Graph Objects
- **Web App**: Streamlit
